# Inkling Three.js Scenes

Four one-shot Three.js scenes written by **Inkling-2-Small** (Thinking Machines, served on Tinker), each from a single text prompt with no edits.

Live: see the GitHub Pages link in the repo's About section.

| Scene | File |
|---|---|
| Medieval village at golden hour | [scenes/village.html](scenes/village.html) |
| Rube Goldberg machine | [scenes/rube-goldberg.html](scenes/rube-goldberg.html) |
| Marble labyrinth game (arrow keys) | [scenes/marble-labyrinth.html](scenes/marble-labyrinth.html) |
| Sunlit living room | [scenes/sunlit-room.html](scenes/sunlit-room.html) |

Each scene was the top pick of five samples for its prompt: samples that failed a headless-browser runtime check were dropped, and the rest were ranked with LLM-as-a-Verifier.
